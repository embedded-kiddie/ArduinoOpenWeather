# Icon Fonts

Thanks to the following for releasing these awesome fonts software.

## WeatherIcons-Symbols

This font file is a custom version of [kickstandapps/WeatherIcons][1] licensed under the [SIL OPEN FONT LICENSE Version 1.1][3].

```bash
./fontconvert WeatherIcons_Symbols.ttf 35 63 90 > WeatherIcons_Symbols35pt7b.h
./fontconvert WeatherIcons_Symbols.ttf 48 63 90 > WeatherIcons_Symbols48pt7b.h
```
## WeatherIcons-Arrows

This font file is a custom version of [erikflowers/weather-icons][2] licensed under the [SIL OPEN FONT LICENSE Version 1.1][3].

```bash
./fontconvert WeatherIcons_Arrow.ttf 30 48 55 > WeatherIcons_Arrows30pt7b.h
```
