The Noto Project Authors (https://github.com/notofonts/latin-greek-cyrillic).

## Making custom fonts file
```bash
../fontconvert/fontconvert NotoSans-SemiBoldAlphabet.ttf 7 32 122 > SemiBoldAlphabet7pt7b.h
../fontconvert/fontconvert NotoSans-SemiBoldItalic.ttf  16 45  58 > SemiBoldItalicNumeric16pt7b.h
```
